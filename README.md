1. Aplikasi ini dibuat untuk memudahkan Team Sales melakukan SO (Sales Order)secara real time.        

2. Dengan fasilitas kirim order, maka admin tidak perlu entry manual setiap barang ke System.

3. Team Sales dapat mencetak Invoice langsung dari HP atau Share PDF.

4. Secara real time team sales mengetahui saldo stock setiap SKU sesusai syncronisasi data terupdate.

5. Dapat menambah Customer Baru dengan klik ikon NOO (New Outlet Openinig)
