Aplikasi ini dibuat untuk memudahkan Team Sales melakukan SO (Sales Order)secara real time.
Dengan fasilitas kirim order, maka admin tidak perlu entry manual setiap barang ke System.
Team Sales dapat mencetak Invoice langsung dari HP atau Share PDF.
Secara real time team sales mengetahui saldo stock setiap SKU seusai syncronisasi data terupdate.
